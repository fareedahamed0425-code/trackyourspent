**trackyourspent** is an elegant, sophisticated day-wise expense manager with auto-calculation, custom categories, and seamless cloud synchronization powered by Firebase. Designed with a premium dark aesthetic.

## ✨ Features

- ☁️ **Cloud Synchronization**: Real-time backup and sync across devices with Firebase Firestore.
- 🔐 **Authentication**: Secure Login & Sign-up via Email/Password or Google Sign-In.
- 🎨 **Premium Aesthetic**: Sophisticated dark UI architecture with buttery-smooth micro-animations.
- 📊 **Day-Wise Ledger**: Track your cashflow and expenses day by day effortlessly.
- 🧮 **Auto-Calculator**: Quickly calculate split bills or tips and record them instantly.
- 🗂️ **Category Manager**: Organize your spending into intuitive custom categories.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/fareedahamed0425-code/trackyourspent.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd trackyourspent
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**
   Navigate to `http://localhost:3000` to see the application in action.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Backend/Auth**: Firebase (Auth & Firestore)
